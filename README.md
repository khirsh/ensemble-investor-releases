# Ensemble Investor — releases

Downloads and the update feed for **Ensemble Investor**, a Mac app from
Ensemble Education, Inc. that keeps a library of your investments and tracks
each one's performance.

- **To install:** download the newest `.dmg` from
  [Releases](../../releases/latest), open it, and drag Ensemble Investor into
  Applications. Requires macOS 27 or later on Apple silicon.
- **To update:** the app updates itself. Choose **Ensemble Investor → Check for
  Updates…** to look right away.

The other files here are read by the app, not by people: `appcast.xml` is the
update feed, and `release.json` names the newest and the oldest supported
build. This repository holds no source code.
